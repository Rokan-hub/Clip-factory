One-time setup (2 minutes)

This page needs a key that lets it press the "Run" button on your GitHub repo for you. The key stays in this browser only.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Token name: clip-factory. Expiration: 90 days.
  3. Repository access: choose Only select repositories, then pick Clip-factory.
  4. Click Add permissions (or open Repository permissions) and set Actions to Read and write. Leave everything else.
  5. Click Generate token and copy it (it starts with github_pat_).
